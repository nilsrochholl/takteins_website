# takteins.de

Fertig gebaute Website von takteins. **Nicht hier bearbeiten.**

Die Quellen liegen in `nilsrochholl/NRO` unter `takteins/website/`.
Dort wird mit `python3 takteins/build.py` gebaut und der Inhalt von `takteins/dist/`
hierher übertragen. Plesk auf b14 holt jeden Push auf `main` automatisch nach
`takteins.de/httpdocs`.
